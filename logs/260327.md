1. 桥接使用的命令行要根据world name进行修改，和文件名无关，现在的完善的sdf是track_lidar4_box,但是world name是custome_track_lidar
```bash
ros2 run ros_gz_bridge parameter_bridge \
  /world/custom_track_lidar/model/turtlebot4/link/rplidar_link/sensor/rplidar/scan@sensor_msgs/msg/LaserScan[ignition.msgs.LaserScan \
  --ros-args -r /world/custom_track_lidar/model/turtlebot4/link/rplidar_link/sensor/rplidar/scan:=/scan
```
## 2. 将目标文件覆盖warehouse并且修改worldname可以避免手动bridge 
3. 创建包节点
```bash
ros2 pkg create --build-type ament_python robot_state_monitor --dependencies rclpy tf2_ros nav_msgs sensor_msgs std_msgs
#运行
colcon build --packages-select robot_state_monitor
source install/setup.bash

# 运行节点
ros2 run robot_state_monitor monitor
```
