> 目的：课前在本机（同机拓扑：平台＋ROS2 同跑 PC）手动跑通"真值图→静态世界→桥接→建图→存图→重定位"全链路，

另一窗口给初始位姿（用第 1 步记录的起点真值，**注意 yaw 弧度制**：88°≈1.536 rad）：
```bash

 "{header:{frame_id:'map'}, pose:{pose:{position:{x:8.08,y:6.24,z:0.0}, \
 orientation:{x:0.0,y:0.0,z:0.695,w:0.719}}}}"
# yaw=1.536 rad（=88°）→ z=sin(yaw/2)=sin(0.768)=0.695, w=cos(yaw/2)=cos(0.768)=0.719
# 若你的 seed 不同，起点真值以 make_gt_map.py 打印为准，四元数按 z=sin(yaw/2), w=cos(yaw/2) 换算
```

## 常见问题速查（本机版）

| 症状 | 原因 | 处理 |
|---|---|---|
| `✅ 已成功连接`不出现 | 网关没起/端口被占/桥在别的目录 | 回查第2步回显与 ss 检查 |
| /scan 无数据进 SLAM | 桥接 QoS 是 BEST_EFFORT；slam_toolbox 用 SensorDataQoS 天然兼容——先查桥是否真的连上 | hz /scan 验证 |
| map→odom 恒等 | 扫描匹配没生效 | 查 /scan 是否有数据、帧名是否 base_footprint |
| 遥控不动 | 2 秒覆盖窗口外＝停车（nav_gateway 无 PPO 兜底）；`,` 后退被截断 | 持续按 `i`；前进转向才有效 |
| AMCL 粒子云发散 | 双实例/初始位姿给错 | pkill 重起唯一桥；初始位姿用起点真值 |
| 地图有残影 | 建图时动过 seed 或跑错过入口（inference_server 回合制） | 确认用的是 nav_gateway；重跑第 2–7 步 |
| **建图效率低**（覆盖 <50%、墙稀） | ①插帧阈值过高（默认 0.5m/0.5rad 才处理一帧）②车速过快 ③贴墙走中央扫不到 | ①yaml 已改 minimum_travel 0.1/0.1 ②teleop `z` 键降速到 ~0.2m/s ③靠中部绕大圈；重启 SLAM 生效 |
| **建图漂移/重影明显**（slip=0.05 下） | 真分叉里程计＋插帧加密＝漂移边密集写进图；直线段激光无纵向约束 | A/B：`--slip 0` 重跑（干净则漂移100%归因里程计分叉）；yaml 已调回环方差 4.0＋loop_search_maximum_distance 6.0（回环容忍更大漂移）；**smear 勿超 0.1（karto 硬校验，0.25 实测启动即崩）**；两圈路径贴近给回环机会；漂移图留档＝不可信区域候选 |
