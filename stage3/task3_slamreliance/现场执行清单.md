## 2. 实验3-1 孪生侧七步（P14–P16，③段主体）

**纪律**：静态世界模式与默认入口 `inference_server.py` **不得同时运行**（同占8000，回合制、6倍墙钟速）；桥接唯一实例。

### ① 真值图＋静态世界（平台端；同机＝本组 PC 开终端A/B）
```bash
cd ~/workspace/zs3_fyue/embodied-sim-lite-master
python make_gt_map.py --seed <组号> --out .     # → map_gt.pgm/.yaml；打印起点真值+障碍表+SHA256
python nav_gateway.py --seed <组号> --slip <本组slip>   # 静态世界 10Hz；--slip 不写即无漂移
```
- [ ] 记录：起点真值 (x,y,yaw°)＝________（rviz 初始位姿按此设）

### ② 桥接（ROS2 端＝本组 PC）
```bash
# 同机（平台与 ROS2 同一台 PC）：直接运行，默认连 ws://127.0.0.1:8000/ws
python ros_bridge.py
# 跨机（平台在笔记本）：SIM_GATEWAY_WS=ws://<笔记本IP>:8000/ws python ros_bridge.py
ros2 topic hz /odom /scan        # 就绪判据：/odom ≈10Hz（nav_gateway）
```
- [ ] 桥接终端出现 `✅ 已成功连接到推理网关！`
- [ ] 若 hz 越数越高/TF 抖动 → 双实例，`pkill -f ros_bridge` 重起唯一实例

### ③ 迁移参数并建图（P14 三纪律：慢 · 两圈 · 判据）
```bash
ros2 launch slam_toolbox online_async_launch.py use_sim_time:=false \
       slam_params_file:=config/mapper_real.yaml
ros2 run teleop_twist_keyboard teleop_twist_keyboard   # 慢速绕行 2 圈
```
- [ ] 慢：转弯时角速度对匹配的影响大于线速度——转弯减速
- [ ] 两圈：第二圈是回环闭合的机会；存图前检查走廊是否接上、起点附近墙体是否对齐
- [ ] 判据：`ros2 run tf2_ros tf2_echo map odom` **非恒等且随行程变化**（恒等＝扫描匹配没生效，闭环存疑）

### ④ 存图·对照真值图
```bash
ros2 run nav2_map_server map_saver_cli -f maps/sim_<组号>
ls maps/     # 两件套 sim_<组号>.pgm + .yaml 缺一不可
```
- [ ] 两件套齐；与真值图叠合对照（黑：真值图　橙：建图）

### ⑤ 互评（P15/P17）
- [ ] 相邻组交换工位，评图不评人；三项（重影/缺口/畸变）1~5 分，**每个分数指出图上位置**
- [ ] 互评打分表双方签字留档

### ⑥ 重定位 → 5点×2条件采样（P16）
```bash
ros2 launch nav2_bringup localization_launch.py map:=maps/sim_<组号>.yaml use_sim_time:=false
# rviz2：Fixed Frame=map；Add LaserScan(/scan) 时 Reliability Policy 必须改 Best Effort（否则一个点也收不到）
# 2D Pose Estimate 给初始位姿（起点真值由 make_gt_map.py 打印）；粒子云收敛后再移动
# 每个标记点静止后：① 读 /amcl_pose（估计）→ ② python truth_probe.py --host <网关IP>（真值；同机=127.0.0.1）
```
- [ ] 每点四项：AMCL估计(x,y,θ) | 真值(x,y,θ) | 误差 | 协方差椭圆目视（小/中/大）
- [ ] 条件 A＝正确初始位姿；条件 B＝初始位姿偏置 1m（位置＋朝向），记 收敛(用时s)/发散/锁定
- [ ] **两条证据链独立**：先记估计、再读真值，互不参照；每点四项记全再移动
- [ ] 标记点分散全场，**至少 1 个置于预判不可信区域**（重影区/长走廊端头/对称角落）
- [ ] 协方差三档锚：椭圆长轴对车长——小 ≤1倍 / 中 1~3倍 / 大 >3倍
- [ ] 条件 B 由一人操作偏置、全班观察时集合切换到 P17

### ⑦ TF 树诊断（验收项）
```bash
ros2 run tf2_tools view_frames     # → frames.pdf
```
- [ ] 四段齐全：map → odom → base_footprint → {base_link, laser_frame}（孪生侧帧名）
- [ ] 频率健康：/odom ≈10Hz、/scan 稳定高频
- [ ] 无 extrapolation（外推错误三类：停发/低频/多机时钟不同步——第1课契约表"时间戳单调"在此兑现）

## 6. 常见坑速查（平台 README 5.8 ＋ 本课）

| 症状 | 原因 | 处理 |
|---|---|---|
| rviz2 /scan 一个点也没有 | QoS 默认 Reliable 与桥接 BEST_EFFORT 不匹配 | 订阅方改 Best Effort（本平台最高频问题） |
| AMCL 粒子云发散、hz 爬升 | 多个 ros_bridge 实例双源发布 | pkill -f ros_bridge 重起唯一实例 |
| map→odom 恒等 | 扫描匹配没生效 | 查 /scan QoS、帧名、use_sim_time |
| tf 报 extrapolation | 某节点 use_sim_time=true 或跨机时钟不同步 | 全链路 use_sim_time:=false；跨机 NTP 对时 |
| 地图墙面重影/畸变 | 24线稀疏雷达+里程计漂移（设计使然） | 调匹配参数；或 slip=0 做对照分离"漂移"与"稀疏"两变量 |
| 障碍物在图上重影成团 | 跑错了入口（inference_server 回合制重摆障碍） | 改用 nav_gateway.py 静态世界 |
